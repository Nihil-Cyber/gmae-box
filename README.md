# Gmae Box

**直接玩：** [https://nihil-cyber.github.io/gmae-box/](https://nihil-cyber.github.io/gmae-box/)

有意義嘅教育遊戲盒。用輕量 Web App 小遊戲，訓練小朋友嘅計算、推理同解難能力。而家由數學起步，之後會陸續加入語文、邏輯、科學等更多類型。

目前第一位玩家角色係 **Wesley**。

原始碼：[github.com/Nihil-Cyber/gmae-box](https://github.com/Nihil-Cyber/gmae-box)

GitHub 檔案頁入面撳 `index.html` **唔會**行起遊戲（只會見到原始碼）。真正打開程式請用上面嘅 GitHub Pages 網址。

## 而家有咩遊戲

| 遊戲 | 練習重點 | 難度 |
| --- | --- | --- |
| 我嘅家園 | 用星星養寵物、換裝飾；可同時放出兩隻，商店可升級範圍同寵物位 | — |
| 加加減減 | 單數、20 以內、不進位雙位加減 | 初級／中級／高級 |
| 乘乘除除 | 1 到 10 乘數表；除法答案少過 25 | 初級乘法、中級／高級加除法 |
| 奧數挑戰 | 規律、填空、應用題、巧算、雞兔同籠 | 初級／中級／高級 |
| 四宮數獨 | 4×4 入門數獨（每行、每列、每個 2×2 都要 1–4） | 初級／中級／高級 |
| 智能數獨 | 6×6 彩色數字，每行／列／2×3 宮格 1–6 不重複 | 初級／中級／高級 |
| 圖形一樣 | 睇兩個圖形，一樣就撳「一樣」，唔同就撳「唔同」 | 初級／中級／高級 |
| 認一認字 | 睇圖認字、睇字認意思、辨相似字 | 初級／中級／高級 |
| 單字配對 | 詞語意思、填缺字 | 初級／中級／高級 |

每局練習題 10 題。第一次答啱會得到星星；星星可以喺家園商店買寵物、裝飾，同升級家園範圍／同時放嘅寵物數量。進度存在瀏覽器本機。

## 點樣運行

### 網上直接打開

手機、平板或電腦瀏覽器打開：

**https://nihil-cyber.github.io/gmae-box/**

每次 `main` 分支有更新，GitHub Actions 都會重新編譯並發布呢個網址。

### 本機開發

```bash
npm install
npm run dev
```

瀏覽器打開終端機顯示嘅位址（本機通常係 `http://localhost:5173/`）。同一 Wi-Fi 下，平板或手機可以用 Network 位址開啟。

```bash
npm run build    # 產出靜態檔，方便之後部署
npm run preview  # 預覽正式版
```

## 願景

Gmae Box 唔只係計數練習。目標係成為一個**有各種意義**嘅教育遊戲集合：

- **數學**：計算、規律、空間（已開始）
- **語文**：認字、詞語、閱讀理解
- **邏輯**：分類、圖形規律、策略
- **科學**：觀察、比較、日常知識
- **生活能力**：時間、金錢、排隊同分享等情境

每一款遊戲都應該有清楚練習目標、適合觸控嘅操作、以及溫和嘅回饋，而唔係用壓力催谷分數。

# 路線圖

Gmae Box 嘅目標係成為一個**有各種意義**嘅教育遊戲盒：每一款遊戲都對應一種可以講得出嘅能力，而唔係純粹攞分。

## 0.1 — 數學起步（而家）

- [x] 單數到雙位加減（20 以內、不進位）
- [x] 1 到 10 乘數表同除法
- [x] 奧數思維（規律、應用、巧算）
- [x] 4×4 空間／規則推理（數獨）
- [x] 星星同本機進度

## 0.2 — 更易堅持練習

- [ ] 自訂玩家名稱（預設 Wesley）
- [ ] 錯題本
- [x] GitHub Pages 一鍵打开
- [x] 星星換家園裝飾同寵物
- [ ] 可選計時（預設關閉，避免催谷）
- [ ] 數獨提示會修正填錯格

## 0.3 — 第二種能力：語文

- [x] 認字／詞語配對
- [x] 朗讀生字（系統粵語）
- [ ] 簡單閱讀理解

## 0.4 — 邏輯同科學

- [x] 圖形一樣／唔同（辨別）
- [x] 6×6 智能數獨（行／列／宮格）
- [ ] 圖形規律、分類
- [ ] 觀察比較（大小、多少、先後）
- [ ] 日常科學小知識（安全、身體、季節）

## 長遠

- 家長睇到嘅練習摘要（唔公開小朋友資料）
- 主題季節活動（新學年、暑假）
- 多語言介面（粵語書面語維持為主）
- 將遊戲盒變成可以加新遊戲模組，而唔使每次改主頁結構

新遊戲加入原則：

1. 講得出訓練邊一種能力
2. 觸控先、大按鈕、即時溫和回饋
3. 有至少兩個難度
4. 唔用驚嚇、羞辱或者過度競爭

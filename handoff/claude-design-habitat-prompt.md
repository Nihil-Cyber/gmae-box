你係兒童產品美術指導。請為教育遊戲盒 **Gmae Box** 入面嘅獎勵空間 **「我嘅家園」** 做一輪完整視覺升級。

呢個唔係賭場、唔係養成懲罰遊戲、唔係 icon pack。係爸爸同小朋友 Wesley 一齊玩嘅溫暖小花園：答啱題目賺星星，用星星領養寵物、擺裝飾、擴建家園。

工程師之後會喺 React + SVG（或透明 PNG）入面實作。請你出設計，唔好出程式碼。

**請全部升級成插畫。禁止再用系統 emoji、禁止再用通用 icon（Lucide、Material、Noto Emoji、flat sticker）當角色或裝飾。**

可以保留「紙本／剪紙劇場」感覺，但物件要係畫出嚟嘅角色同場景，唔係貼喺畫面上面嘅符號。

## 玩法（會影響構圖，請跟住畫，唔好刪）

家園有兩個主 Tab：**家園**、**商店**。商店再分三頁：**寵物**、**裝飾**、**升級**。

1. 劇場入面可以同時放出最多 6 隻寵物（預設 2 隻，商店可買多一隻位，加到 6）
2. 玩家可以**拖**寵物同裝飾去搬位；輕輕撳寵物 = 摸一摸；撳裝飾 = 收起
3. 寵物會喺玩家擺佢嘅附近**自己慢慢行**（行、停、輕輕轉身），唔好畫死晒企喺正中間
4. 商店可買「家園擴建」：草地同天空逐級變大（0→3 級）
5. 兩條狀態：飽肚、開心。摸免費加開心；餵零食扣 1 粒星星加飽肚
6. 寵物唔會死、冇懲罰、冇倒數、冇紅色交叉、冇灰色禁用掣

## 視覺方向

**要**
- 兒童繪本／剪紙劇場／木製玩具盒
- 奶油紙底、暖色、飽滿圓形、清楚剪影
- 每隻寵物有自己嘅毛色、臉、身體比例，遠睇都分到邊隻
- 裝飾係場景物件：有體積、有接觸陰影、有遠近（天空物細同淡少少，地面物貼草、有落點影子）
- 紙本陰影：實色色塊向下偏移，唔好大面積高斯模糊
- 開心時天空更亮、更藍；平靜時柔和一點

**唔要**
- emoji、icon、flat sticker、閃粉貼紙灑滿畫面
- 3D 塑料渲染、賽博、暗黑、寫實毛髮
- 紅色錯誤、灰色禁用、骷髏、血、驚嚇
- 把 UI 按鈕畫成遊戲搖桿或廣告彈窗
- 裝飾遮住寵物臉

## 請分開畫嘅素材（工程師要接入程式）

全部透明底、正面或 3/4 正面、粗描邊、剪影清楚。寵物同裝飾唔好連 UI 一齊燒入去。

### 寵物 · 6 隻 · 每隻兩個表情

每隻輸出：`normal`（開眼，溫柔望住你）同 `happy`（閉眼笑，摸完／餵完用）。

| id | 名 | 性格（畫入體態） |
|---|---|---|
| chick | 小雞 | 圓、毛茸茸、剛出世、好黏人 |
| rabbit | 兔仔 | 長耳、後腳隨時要跳 |
| cat | 小貓 | 瞇眼曬太陽、柔軟 |
| dog | 小狗 | 搖尾、耳仔跟住郁 |
| panda | 熊貓 | 圓、慢、食飽想瞓 |
| dragon | 小龍 | 親切守護者，唔好恐怖、唔好噴火嚇人 |

建議畫布：正方形 512×512。腳底留空，方便落地。側身行走可以靠水平翻轉，唔使出跑動序列。

### 裝飾 · 15 款

天空（掛上半部，唔好搶寵物）：太陽、月亮、星空、彩虹、白雲  
地面（貼草、有接觸影）：小花、大樹、蘑菇、小屋、噴泉、燈籠、氣球、小池、木欄、果樹

建議畫布：正方形 384×384。小屋／大樹／果樹可以高一點，但仍放喺方形入面。

### 場景零件

- 劇場外框：奶油卡、圓角、紙本厚度
- 三層山丘（遠中近），頂邊有紙張切邊
- 內圈白色虛線縫線
- 空狀態布墊
- 空狀態紙條 + 和紙膠帶
- 商店雨篷（間條 + 波浪下緣 + 木棍）
- 升級卡插畫兩張：多一隻位、家園擴建（細、中、大三級草地可以畫成同一套由細變大）

### 小元件（都要插畫，唔好 emoji）

- 星星（頂欄膠囊、價格、餵零食扣 1 星）
- 返回箭嘴（圓掣入面）
- 摸完飄起嘅心心（3–5 粒，要畫出來）
- 餵零食飛過去嘅曲奇／餅乾
- 飽肚、開心兩條狀態嘅小標記（可食／可摸嘅符號，仍然唔好用系統 emoji）

## 構圖規則

- 寵物永遠係視覺主角。1 隻時可以較大；2–3 隻中等；5–6 隻細一點但仍清楚。
- 多寵物時要自然散落草地，有前後、有輕微遮擋，唔好一條水平對齊。
- 擴建後嘅家園：山更闊、天更高、物件之間有呼吸位。
- 拖動中嗰件 z-index 最高，唔好穿透外框。
- 商店卡圖示區約正方形，角色要完整入框，唔好斬頭斬腳。

## 匯出方式

1. 畫面 A–G：PNG，標好檔名（`A-habitat-happy.png` 如此類）
2. 寵物 6×2、裝飾 15、小元件：SVG 最理想（封閉路徑、少漸層也可以）；否則透明 PNG
3. 列一個圖名清單對應上面嘅 id（chick、rabbit、sun、flower、upgrade-slots、upgrade-yard…）
4. 如果用畫布，請用 Share › Export，方便工程師放入 `handoff/screens/` 同 `handoff/art/`

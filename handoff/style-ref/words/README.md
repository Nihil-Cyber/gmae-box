# 認字／單字 · 交俾其他 AI 畫圖

遊戲「睇圖，邊個字／詞先啱？」而家用系統 emoji。請畫貼紙圖取代。

**唔使畫**：只顯示漢字本身嗰啲題（「呢個字係咩意思？」、填缺字、睇兩個相似字）。嗰啲繼續用字，唔用圖。

## 你點做

1. 開 Claude Design（或其他畫 SVG 嘅 AI）
2. 夾風格：`../sheet-pets.svg` + `../pets/chick-normal.svg` + `../decor/flower.svg` + `../decor/sun.svg`
3. 將 `PROMPT.md` 成段貼上去（可以分批：先 easy 認字，再 medium／hard，再單字）
4. 畫完放 `../new/words/{id}.svg`，檔名一定要同清單 id 一模一樣
5. 叫 Cursor 搬入遊戲

## 格式（一定要跟）

| | |
|---|---|
| 檔 | **SVG**，一個 id 一張 |
| 畫布 | `viewBox="0 0 256 256"`，寬高 256 |
| 底 | **透明**，唔好鋪滿色卡 |
| 影 | 底部淺棕橢圓 `#2B2118` opacity **0.13**，**唔好模糊** |
| 風格 | 同寵物：簡筆圓塊、實色填、少漸層 |
| 眼（如果有動物／人） | 細深棕橢圓 + 一點白光；唔好大閃眼 |
| 色 | 紙 `#F6E7C1` 墨 `#2B2118` 太陽 `#F7C948` 蜜糖 `#F2B04A` 陶土 `#D9784F` 薄荷 `#9ED4AC` 珊瑚 `#E24C3B` 天藍 `#2B78B5` 葡萄 `#5A4A8A` |

**唔要：** 系統 emoji、寫實照片、毛髮、3D、暗黑、字寫喺圖入面（圖本身要唔識字都睇得明）。

共 **70** 張。認字 52 張（每個字獨一無二，唔好兩張都係太陽）。單字可以共用認字嗰張（見 PROMPT 對照表）。

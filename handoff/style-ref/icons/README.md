2. 夾風格：上一層 `sheet-pets.svg` + `pets/chick-normal.svg`（再加一隻 `new/pets/` 都得）

5. 畫完嘅 SVG 放返 `icons/new/{id}.svg`，跟下面檔名。之後叫 Cursor 搬入遊戲。

畫布：遊戲卡 **256×256**；頂欄同小貼紙 **128×128**；吉祥物 **120×120**。透明底。
